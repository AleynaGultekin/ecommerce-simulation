# 🛒 E-Commerce Simulation (Java)

An end-to-end Object-Oriented Programming (OOP) retail desktop application built in Java with a Swing Graphical User Interface (GUI), simulating real-world e-commerce interactions.

## 📌 Project Overview
This application models the full lifecycle of an online shopping platform—from account registration and catalog navigation to shopping cart operations, automated checkout, and real-time inventory management.

## 🔑 Key Features
- **User Profile & Management:** Handles user registration, credentials, delivery addresses, and personal wishlists.
- **Product Catalog & Inventory Control:** Real-time stock tracking with dynamic stock reduction and availability validation upon checkout.
- **Shopping Cart & Checkout:** Seamless item insertion, total cost computation, and order placement.
- **Secure Transaction Handling:** Encapsulated credit card processing and order validation mechanics.
- **Interactive Swing GUI:** User-friendly interface providing instant feedback and visual controls.

## 💻 Tech Stack
- **Language:** Java (JDK 11)
- **GUI Framework:** Java Swing
- **Architecture & Design:** Object-Oriented Analysis & Design (OOAD), UML Class Diagrams
